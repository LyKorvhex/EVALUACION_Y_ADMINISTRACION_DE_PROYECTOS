- Rentabilidad: Se refiere a si un proyecto generará más ganancias que la inversión.

### Qué es un proyecto?
Se refiere a la búsqueda de una solución a un problema individual o colectivo. (Debe ser una solución inteligente).

### Inversión
Se refiere a aplicar esfuerzo para postergar un beneficio inmediato, para obtener un beneficio futuro.
- Inversión financiera: Genera rendimientos (intereses).
- Inversión económica o real: Genera rentabilidad.

### Proyecto de inversión
Se refiere a la búsqueda de una solución inteligente que satisfaga una necesidad que se le asigna un monto capital de tal manera que proporcione un servicio útil de forma eficiente, segura y rentable.

### Evaluación de un proyecto de inversión
Todas aquellas actividades que se relacionen con la toma de decisiones respecto a un proyecto de inversión.
Toma importancia una vez que se tiene como objetivo saber la rentabilidad del proyecto con las características antes mencionadas.

Una inversión inteligente actualmente requiere de un proyecto muy bien estructurado, evaluado correctamente. Gracias a esto, se pueden asignar correctamente recursos e insumos y se pre-visualizará si este será verdaderamente rentable. Las decisiones pueden ser de aceptación o rechazo.
